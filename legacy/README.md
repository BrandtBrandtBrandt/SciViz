# Original Streamlit / Baseten prototype

This is the original SciViz implementation, preserved as project history. It used a Streamlit frontend, paid OpenAI calls and a Baseten-hosted Truss/ComfyUI workflow.

For the current Hugging Face backend and browser demo, start with the [repository README](../README.md).

The files in this folder are not part of the current deployment. Credentials are not included, dependencies are historical and the old Baseten deployment may no longer exist. These instructions are archival rather than a supported one-command setup.

- `main.py`, `util.py`, `requirements.txt`: original application and dependencies.
- `baseten/`: original Truss configuration, workflow and deployment notes.
- `README.original.md`: original repository introduction.
